# Changelog

## 0.1.0 - GizVFX split out of Gizpix
GizVFX is the former `pixfx` of Gizpix, moved into its own tool (`gizvfx.py`, package `gizvfx`, user recipes in `~/.gizvfx/recipes`, env `GIZVFX_RECIPES`). Sprite sheet JSON carries `meta.gizvfx` (and the old `meta.pixfx` key). The GIF/sheet writer is its own copy, so the tool does not need the rest of Gizpix.

- New `fix` command: check an effect, repair what can be repaired (cropped canvas, pinholes, lone pixels, too many colours, one-shot that does not end empty), write the files and `NAME_fix.txt`, list what is left.

- Found by a blind test (an agent that had only the repo): option values can be negated ("-$height") and a non-number gives a clear error; `poly` shape `heart`; `painted` writes a contact sheet; `fix` separates problems (exit 1) from advisory notes; docs: palette rule for layers with their own palette, `curve` is one number, the painted section is a list.

- Second blind test: `$a+4`, `$a-4`, `$a/2` in recipes; a `bolt` colour `rim` no longer clashes with the generic `rim`; `check` and `fix` name the edge and the first frame that touches it; `fix` stops at the 256 px canvas limit and says so instead of crashing; contact sheets are page-shaped grids (painted ones no longer one 21000 px strip); a painted `smear` is a soft streak, not stacked discs; docs: defaults, light-background note, `drift` in one-shots.

- Third blind test: contact sheets are about as wide as tall (tiles shrink instead of the sheet becoming a 4000 px column); `fix` cuts a cropped canvas to what the effect really covers in one step; `list` marks recipe or code; `fix --name`; the motion pop note says when it is expected; docs: `beam` and `erode`, particle star colour, output names.

- `particles` `drop: true`: particles stay where the layer was when they were born, so a layer moving along `at` leaves a trail with one layer (a blind test had to build it from 16 layers). Works in both renderers.

History carried over from Gizpix 0.2.0:
- Painted: glows fall off in the pixel renderer's bands (soft edges), watercolor has more body and colour on dark grounds. Beam colours across the width match the pixel beam.
- Painted, the last small differences from the pixel frames: `rim`, a true gradient across a `beam` with a white-hot line, core-shaded dots (coin-burst is gold again), thicker speed lines, a glow with the pixel renderer's flat first step (shield-bubble, bomb-fuse), crossing-line sparkles for `star`, more body in watercolor.
- Painted: native `include`; a white-hot beam core; glows are added as light over everything beneath (orbs and beams are as bright as in the pixel version); the ramp colours follow the pixel steps; smear trails use 14 copies. After a frame-by-frame review of all 31 recipes against the pixel frames.
- Painted: native smooth `funnel`, `bolt`, `rays`, `poly` (only `include` still goes through the smooth upscale); brighter `beam`, banded `ring`, thicker `star` and `bolt` after a frame-by-frame review against the pixel frames.
- Painted: native smooth `particles`, `blob`, `star`, `orbit` and `beam` (the particle and blob simulations are shared with the pixel renderer: its output is byte-identical to before), and `smear`, `erode`, `outline` in the painted version. Only rays, bolt, poly, funnel and include still go through the smooth upscale.
- `gizvfx painted` now works for every shipped recipe: layers without a native smooth version are drawn as pixels and smoothly upscaled, glow stays soft in every style; painted ring/glow follow `squash`, `arc` and the pixel ring geometry, discs are shaded; `lineart` keeps thin parts as one line; `glitch` no longer wraps rows or darkens by alpha.
- Painted: `glitch` takes `--intensity` and `--hold`; new style `lineart` (thin glowing outline); `brush` takes `head` (where it is fattest); `chalk` is stronger. `melee/claw-scratch` and `impacts/ink-burst` use pointed strokes, `melee/speed-dash` has a diagonal hatch.
- Painted style `glitch` (sliced rows, RGB split, scanlines, new every frame). Pixel `splat` gets an outline, no white middle and a gloss spot; pixel `speedlines` are wedges; `linocut` and `chalk` keep thin lines.
- New layers `burst` (comic star burst), `speedlines` (radial or parallel) and `splat` (blob, droplets, drips), and recipes `impacts/pop-burst`, `impacts/paint-splat`, `melee/speed-dash`; both renderers draw them. Painted styles `linocut` and `stencil`.
- `gizvfx painted --style ink|watercolor|comic|chalk`: four looks for the painted version of one recipe (watercolor wet edges and granulation, comic flat colour with outline, chalk broken coverage).
- New layers `brush` (ink stroke with bristle lanes that dry out; the head runs past the path so one-shots end empty), `hatch` (parallel-line shading) and `halftone` (comic dots), and three recipes that use them: `melee/ink-slash`, `melee/claw-scratch`, `impacts/ink-burst`.
- `gizvfx painted ID`: the same recipe drawn smooth at 4x with a real alpha channel (layers brush, hatch, halftone, glow, disc, ring). Technique ideas from reading cloveric/claude-drawing (MIT); no code copied.
- Colour limiting counts strongly saturated pixels 3x, so a small accent (a red spark in a blue effect) keeps its own palette slot instead of being merged into a neighbour. Idea from reading cloveric/claude-drawing (MIT); no code copied.
- Recipe language: `poly` (crystals, rocks, shards), `stamp` (your own PNG up to 32x32 from the recipe's folder), `include` (an effect inside an effect, 2 deep). Every recipe is now limited (40 layers, canvas 8 to 256, particles 400) and `gizvfx import FILE.json` validates, renders, reports and keeps a copy in `~/.gizvfx/recipes`. New recipe: crystal eruption.
- Recipe language: curved paths (`at` with 3+ points) and `spin`, per-step `ease` lists, `blob` modes `flame` and `ring` (`drift`, `stagger`), particle shapes `bubble` and `shard`, a whole-effect `style` pass (outline, rim, shadow) and palette roles (`"@role"`). New recipes: curving orb, dust ring; soul wisp (a real flame silhouette) and acid splash (flat puddle, popping bubbles) redrawn.
- Recipe language: `smear` (a fading, shrinking trail of any moving layer), `outline`/`rim`/`erode` on every layer, `beam` drawn as one distance field (`core`), `funnel` `profile`/`bend`/`ripple`; `arc` `trail` renamed `tail`. `gizvfx check --report`: mesh dithering, flat colour, lone pixels, empty frames, motion pops, with a fix per flag. New recipe: comet; tornado, soul wisp, vampire drain and smite redrawn.
- Recipe language: `funnel` layer (swirling column), particle `target` + `curve` (fly from a spawn area to a point), layer `wobble` (snaking, swaying). Tornado, soul wisp, vampire drain and portal redrawn with them; `gizvfx palettes` lists the palette names.
- Recipe language: `blob` `erode` (dissolve from the edge), `glow`/`rays` `squash`, particle `shape: star`. Smoke puff redrawn with them.
- `gizvfx` output cleanup, found by running `pixel_lint` over every effect: the additive glow used to make 120+ near-duplicate colours (torch) and half-transparent pixels. Every effect is now limited to one shared palette of 24 colours by default (`-o colors=N`, 0 = off), and `-o hard=true` makes glow dithered on/off with no half-transparent pixels. Recipe language: values may have more than two keys (`[0, 1, 0]`), options can be scaled (`"$reach*0.5"`), `blob` takes `lit`, `bolt` takes `rim`, `beam` takes `shade: flat`; a ring thinner than a pixel no longer draws as dots. The poison-cloud, shield-bubble, fire-breath, energy-orb and smoke-puff recipes were redrawn after a review.
- `gizvfx` recipes: describe an effect as a JSON file of layers (glow, disc, ring, star, particles, blob, bolt, rays, orbit, beam, arc) with animated values, options and a palette, and render it like any other effect (`gizvfx render my.json`). `gizvfx schema` lists every layer and key, `gizvfx recipe ID` prints a shipped recipe to copy, and mistakes are one-line errors naming the closest correct key. Twenty-one recipes ship (vampire drain, tornado, smite, bomb fuse, portal, acid splash, soul wisp: written blind by an agent that had only the handout, all passing `gizvfx check`; energy orb, poison cloud, level up, teleport, blood hit, fire breath, smoke puff, lightning strike, shield bubble, ice spear, meteor impact, fire wall, summoning circle, coin burst); `gizvfx check` covers them like the Python effects.
- `gizvfx`: code-drawn pixel effects (13: torch, fireball, small explosion, hit spark, shockwave, lightning bolt, frost nova, heal, magic circle, coin sparkle, slash, rain, snow). Two buffers (pixels and additive light), effects as functions of time with a seeded generator, 22 palettes or your own, GIF + sprite sheet + JSON export, `gizvfx check` (deterministic, loops close, one-shots end empty, nothing cropped).
